# 🎂 Erika's Sweet 17th Celebration Portal (V4 - Two Prizes)

Website interaktif perayaan ulang tahun ke-17 untuk Erika dengan gaya visual *Deep Elegant Blue* & *Ultra Glassmorphism*. Struktur kode pada versi ini telah dipisah menjadi 3 bagian utama (`index.html`, `style.css`, dan `script.js`) agar pengelolaan kode menjadi jauh lebih rapi, bersih, dan mudah dimodifikasi tanpa mengubah fitur asli bawaan projek.

---

## 📁 Struktur Dokumen Projek

Pastikan semua file di bawah ini berada di dalam satu folder direktori yang sama agar program dapat berjalan dengan normal:

```text
├── index.html        # Struktur halaman & komponen teks ucapan
├── style.css         # Gaya visual, tema warna, efek kaca (Glassmorphism), & animasi
├── script.js        # Logika transisi kartu, efek partikel, & integrasi webhook
├── wpp.png          # Gambar latar belakang (Background Wallpaper)
├── music.mp3        # Musik latar belakang (Audio Driver)
├── gif1.gif         # Aset GIF untuk Card Halaman 1
├── gif2.gif         # Aset GIF untuk Card Halaman 2
├── gif3.gif         # Aset GIF untuk Card Halaman 3
├── gif4.gif         # Aset GIF untuk Card Halaman 4
└── gif5.gif         # Aset GIF untuk Card Halaman 5 (Hadiah)
